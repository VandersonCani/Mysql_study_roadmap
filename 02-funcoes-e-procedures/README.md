# Functions e Procedures - MySQL

## Objetivo
Praticar funções nativas e criação de procedures no MySQL.

## Etapas

### 1. Funções básicas
Uso de CONCAT, UPPER, LOWER, NOW e DATEDIFF.

### 2. Aplicação em tabela
Manipulação de dados da tabela clientes.

### 3. Procedure simples
Criação de procedure para listar dados.

### 4. Procedure com parâmetro
Busca dinâmica de registros.

## Resultado
Procedures funcionando corretamente e consultas otimizadas.
